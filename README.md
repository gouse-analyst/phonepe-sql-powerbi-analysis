# phonepe-sql-powerbi-analysis
End-to-end PhonePe transaction analytics project using Power Query, MySQL, SQL, DAX and Power BI, covering data cleaning, EDA, data modeling and interactive dashboard development.

## PhonePe Transaction Analytics

## 📌 Project Overview
An end-to-end data analytics project using PhonePe transaction data to analyze
transaction trends, services, payment status, and user behavior.

## 🛠️ Tools Used
- Excel
- Power Query
- MySQL
- SQL
- Power BI
- DAX

## 🔄 Project Workflow
Excel → Power Query → MySQL → SQL Analysis → Power BI → Dashboard

## 🧹 Data Cleaning
- Removed duplicate records
- Handled missing values
- Removed invalid transaction amounts
- Cleaned text inconsistencies
- Standardized dates and data types
- Validated user and transaction data

## 📊 SQL Analysis
Performed analysis on:
- Total transactions and transaction amount
- Payment status
- Service and service type
- Monthly transaction trends
- User transaction behavior
- Top users
- Month-over-month transaction changes

## 📈 Power BI Dashboard
Created an interactive dashboard to analyze:
- Transaction KPIs
- Service performance
- Payment status
- Monthly trends
- User demographics
- Top users

## 💡 Key Insights
- Loans generated the highest transaction amount.
- Successful transactions represented the majority of transactions.
- Transaction amounts varied across services and months.
- Different age groups showed different user representation.

## 📁 Dataset
The project contains two main tables:
- All_Users
- All_Transactions
